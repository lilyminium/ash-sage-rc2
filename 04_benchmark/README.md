# Benchmarks

This directory compiles benchmarking scripts. In general only data is computed and collected here, analysis is done in `../05_analysis`.

- qm/ : benchmarks to QM data
- phys-prop/ : benchmarks to physical property data
- sfes/ : benchmarks to solvation free energies
- rbfes/ : relative binding free energies. Notably, unlike the other benchmarks, we typically collaborate with OpenFE to compute these and download results from Zenodo (links in directory). Scripts in this directory simply collate data.
- test-cases/ : looking at specific test cases.
