# RBFE results

RBFE results are generally computed by OpenFE and uploaded to Zenodo. The data in `data/jacs` contains this data.

The `run-combine-data-with-reference.sh` script combines computed data with experimental data into two single dataframes: one for `output/dG.csv` and one for `output/ddG.csv`.

Zenodo links:

- 2.3.0: https://zenodo.org/records/17408549
- 2.2.1: https://zenodo.org/records/17408567
